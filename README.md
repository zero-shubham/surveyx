## Surveyx - a platform to run and manage surveys.

This a dummy project, with an intent to implement and experiment around k8s, terraform, OpenTelemetry. 

### Objectives
1. Use k8s to run all required services.
2. Implement auto scalability and high availability of services. (except DB and Kafka)
3. Have IaC using Terraform.
4. Have apt observability and monitoring with OpenTelemetry.
5. Make use of best practices for security.
